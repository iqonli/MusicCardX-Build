# Windows桌面交互第二轮

仅修改MusicCardX-Build/windows-desktop。Android布局与背景公式不变。

- 左侧垂直导航分为输入、工作台。输入保留普通表单；工作台按原JS的分组顺序排列，设置收纳在顶部，参数不足宽度时换行，文字表格独立滚动。
- Windows界面使用已安装Segoe UI，表格中文回退微软雅黑；卡片字体仍独立。宿主开启Per-Monitor V2 DPI awareness并响应WM_DPICHANGED，避免窗口整体按位图拉伸。字体绘制仍由Flutter负责，未将整套UI改写成GDI。原生预览工具栏使用系统消息字体、灰度抗锯齿。
- 卡片和界面字体入口改用Win32 ChooseFont系统对话框；保留字重与斜体。配置导入包含缺失字体时，先询问，再显示缺失清单，逐项选系统字体，最后确定后统一替换同名引用。取消不修改配置内字体名。
- 主窗口滚轮使用180ms缓动，连续滚轮累加目标；点击立即停止。博览会使用独立窗口、原生网格与平滑滚动，首次最大化，后续记住窗口正常尺寸及最大化状态，打开时居中。每行1—10个，滑动条和输入框同步；每次生成20个。
- “渲染并发”指同时生成卡片的任务数，不是单算法线程数。每个C++背景调用原有最多8线程逻辑，所以并发上限为逻辑CPU数除以8后限制在1—4，默认1，超限输入自动约束。关闭/重新生成会取消后续任务，并通过批次号拒收旧批次结果。
- 预览窗口和工作台均有尺寸、毫秒、Input、Copy seed、刷新、复制、快速保存、保存。预览改传原始RGBA，不再PNG编码后由WIC解码；隐藏后暂停预览传输。只压缩/缩小独立预览传输图，不改变导出倍率和原始图片。
- 参数修改不再触发整个应用的主题通知。Windows恢复焦点不重新扫描全部系统字体。Flutter UI isolate显式使用独立线程。
- Flutter窗口本身默认使用硬件渲染；新增“优先高性能GPU”，调用Flutter3.47.9 DartProject.set_gpu_preference，选择高性能设备或交给系统决定，重启生效。这不是强制开关硬件加速，也不会把CPU背景改成GPU算法。来源：Flutter3.47.9 engine/src/flutter/shell/platform/windows/client_wrapper/include/flutter/dart_project.h。
