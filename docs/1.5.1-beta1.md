# MusicCardX 1.5.1-beta1 (Build testing)

Experimental changes are limited to iqonli/MusicCardX-Build; the production repository is unchanged.

The lightFlow V2 background no longer computes the explicit sine ribbon or its highlight. Existing color fields, coordinate distortion, fifth-color blending and seeded haze remain intact.

The third seed-derived parameter is now haze_scale sampled continuously between 1 and 6 using FlowBenchSeedV7|<seed>|lightFlow|haze_scale. It replaces the unused ridge_frequency. warp_strength remains 0..1.2; ridge_strength remains 0..0.72 and now only affects haze luminance.

Android app version: 1.5.1-beta1+36. CI defaults to arm64-v8a; artifacts retained for three days.
