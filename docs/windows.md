# MusicCardX Windows x64

## 构建与交付

仅在MusicCardX-Build的windows-desktop分支开发。正式源码基线：iqonli/MusicCardX main `ddfc3e40a9a2270b9abcfbfef3d25b448887d46a`，业务代码与Build基线一致。Android原生文件和背景算法未修改。

Actions工作流：`.github/workflows/build-windows.yml`。Windows 2022 Runner、MSVC、Windows SDK、Flutter3.47.9、Dart3.13.7。流程依次执行依赖解析、静态分析、原有测试、Windows适配测试、Release构建、完整运行目录打包和SHA256清单生成。不会创建GitHub Release。

下载Actions中MusicCardX-Windows-x64产物，解压内层ZIP，运行MusicCardX.exe。请保留同目录DLL和data目录。绿色包附带MSVC运行库、mcx_background.dll和许可证。

源码包由同次提交的git archive生成。files.sha256.json记录相对路径、字节数和SHA256，供未来安装器读取；目前没有安装器或更新器。

## 使用

工作台自上而下为歌曲信息和封面、背景、颜色、种子、文字表格、项目属性、歌词和分隔线。参数区域可折叠，窄窗口参数自动换行；宽表格单独横向滚动。表格与属性区修改同一份CardDocument，并使用原有参数校验与渲染调度。

预览为独立普通窗口，不置顶；标题显示尺寸、耗时、倍率和种子，按钮为快速保存、保存、复制。关闭预览仅隐藏窗口，可从工作台重新打开。

Ctrl+S快速保存，Ctrl+Shift+S另存为。Ctrl+V在非文本编辑状态下读取剪贴板文件、图片、JSON或歌曲分享文本；输入框保留普通文本粘贴。拖入多个文件会逐个确认导入；取消某个文件后继续处理其余文件。不支持的文件和失败信息会显示在状态消息中。

快速保存沿用格式、质量、倍率、文件名模板及同名避让；保存每次打开系统另存为对话框。复制使用PNG和CF_DIBV5图片格式。单边32768、总像素100000000均为建议上限，超出仍可确认继续。

Windows字体选择器读取DirectWrite系统字体文件，Dart在后台解析实际字体面和可变轴。预览、字重编辑和输出继续使用现有字体渲染代码，不使用ClearType截图。旧配置保留字体名，缺失字体按现有字体回退处理。Android字体导入、ZIP和ezCD功能保留，Windows不显示这些操作。Android Activity快捷调用区域不在Windows显示，AI提示词流程保留。

## 配置

默认以EXE所在目录计算Config路径，与启动工作目录无关。在设置中可以切换到本机LocalAppData下的IQ Online Studio/MusicCardX。位置指针保存在该AppData目录中。状态文件使用JSON校验、临时文件、备份、MoveFileEx替换。当前封面使用Config内副本并以相对路径保存，移动绿色包后仍可读取。

迁移先复制、逐字节验证，再提交位置指针；原目录保留。发生错误不切换活动目录。外部图片输出目录不会随配置目录迁移。

## 架构与范围

lib/desktop/platform_io.dart是平台适配边界，兼容原有MethodChannel调用方式。Windows Runner使用Win32/COM文件对话框、WIC图片解码、Win32剪贴板和DirectWrite字体枚举。音频Tag解析继续在Dart isolate执行；在线搜索与标题格式化、OpenCC、渲染和九种背景复用现有代码。

lib/desktop/music_input.dart提供经过标准化的内部数据输入对象，包含来源、字段、歌词、封面引用、事件类型和时间。没有IPC服务、播放器检测、自动覆盖、独立桥或foobar插件。

## 启动宿主修复

显式显示Flutter子窗口、请求首帧重绘。初始化时先显示加载界面，异常会显示错误和重试入口。关窗等待保存回执，5秒无回执时退出，避免启动失败后无法关闭。EXE、主窗口和预览窗口使用现有APP图标。Actions从绿色ZIP解压启动，等待编辑器完成首张渲染，再发送原生关窗消息并验证进程退出；该检查不代替完整手动交互测试。
