# Windows交互性能调整

本次保持出图倍率、背景参数、随机种子和图片编码不变。

- 渲染状态和导出进度局部刷新，不再每一步重建整个编辑器。
- 表格缓存文字宽度；取消嵌套横向滚动容器；滚动内容独立重绘。
- 快速滚轮累计最多240逻辑像素，反向立即改变方向，固定速度，无惯性加速。
- 环境色没有变化时，不重复刷新工作台。
- 自动保存不再扫描缓存目录；保留定时及退出清理。
- Windows界面默认读取系统消息字体，不继承Android的显示字体。卡片字体独立设置。
- Windows字体直接使用已安装家族，不再提取TTC并重新注册。字体匹配、文件元数据有界缓存；字体文件变化时更新索引。
- C++背景的最后一张已解码图像复用，引用独立释放。
- 原生预览和博览会缓存缩放后的位图，重绘只复制；图片或控件大小变化后重新缩放。

## 验证

Actions运行静态分析、全部测试、Windows Release编译、DLL验证和启动检查。
`desktop_performance_test.dart`检查字体缓存损坏恢复，以及四种原生背景在不同倍率和文字修改后，缓存与重新计算的逐字节一致性，并记录首次/重复渲染耗时。测试引擎耗时不等于用户电脑的Release性能。

绿色包启动检查新增连续缩放窗口、双向滚轮消息和窗口响应检查，结果写入`diagnostics/interaction.json`。这个检查证明原生窗口响应，不能代表Flutter动画帧率。

仍需实际电脑确认：不同DPI/缩放比例下中文UI清晰度、显示器刷新率下的动画体验，以及大量字体/大封面场景。未宣称60/120fps或与其他应用等速。
